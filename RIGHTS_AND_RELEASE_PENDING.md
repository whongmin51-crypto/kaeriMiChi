# Rights and release decisions pending author action

This directory is local staging only. It is not a public repository, an accepted license grant, a journal submission or proof of public FAIR availability. Authors must select the release route and verify permissions before deposit.

1. **Own code/data license:** choose an appropriate license for the authors' original code, derived results, fitted models and documentation. No license has been selected here, because authorship/ownership and institutional requirements were not supplied.
2. **Third-party material:** Janus records originate from the GANN companion repository (`https://github.com/syd-c/GANN`) and the associated publications; HetDB/C2DB records originate from the cited database providers (`https://2dhub.org/hetdb/hetdb.html`, `https://cmr.fysik.dtu.dk/c2db/c2db.html`). Check the exact source-version terms governing data, structures, code and model redistribution. Public access alone does not establish an unrestricted redistribution license. Existing provenance and hashes must remain intact.
3. **Dependencies:** NumPy, PyTorch, scikit-learn, XGBoost and other packages are not redistributed as part of this staging directory; use their package-manager distributions and retain their own license conditions.
4. **Public route:** choose a versioned repository or archive, add a stable record identifier/DOI and machine-readable metadata, state how third-party inputs can be accessed legally, and expose all files necessary for the declared reproduction scope.
5. **Manuscript link:** after the access route actually exists, update the manuscript's data/code availability statement with the real repository URL/DOI, version and access terms. Do not claim a public DOI or public release while the materials exist only locally.
6. **Author checks:** fill accurate authors/contributors, affiliation/funding/competing-interest information; complete the human scientific review; verify that derived data and model distributions are authorized.

Historic source provenance is retained as factual research metadata, including references to earlier configuration development. The current fitted weights and evaluated records included here use Janus and HetDB. This directory does not rewrite historic scientific records or claim that configuration development occurred independently of the previous study.
